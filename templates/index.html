Panduan Menghubungkan Supabase PostgreSQL

Untuk menghubungkan database ke Supabase, buka file .env di root project dan masukkan connection string Anda pada variabel DATABASE_URL:

DATABASE_URL=postgresql://postgres.[PROJECT-REF]:[YOUR-PASSWORD]@aws-0-[REGION].pooler.supabase.com:6543/postgres?sslmode=require
Setelah file .env diubah, restart container dengan docker compose restart web atau jalankan migrasi database dengan docker compose exec web python manage.py migrate.
